
# Dataset Information

## Dataset Name
Student Performance Dataset

## Source
UCI Machine Learning Repository

## Dataset File
student-mat.csv

## Description
This dataset contains information about students, including age, study time, absences, previous grades and final Mathematics grades.

## Download
https://archive.ics.uci.edu/dataset/320/student+performance

## Purpose
This dataset is used for exploratory data analysis, statistical analysis and visualization using R.
